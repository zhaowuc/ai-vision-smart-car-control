# Pinout

本文件从当前固件源码整理，用于 GitHub 展示和复现。若硬件版本变化，请同步更新。

## ESP32-S3

- `STM32_RX = 2`
- `STM32_TX = 1`
- `ARM_RX = 20`
- `ARM_TX = 19`
- `OLED_SDA = 36`
- `OLED_SCL = 35`

## STM32F103

- 左前轮：`PA0`, `PA6`, `PA5`
- 右前轮：`PA1`, `PB0`, `PB1`
- 左后轮：`PA2`, `PB12`, `PB13`
- 右后轮：`PA3`, `PB14`, `PB15`
- LED：`PB8`
- 蜂鸣器：`PA15`
