# 问题与解决方案

## 1. 多设备链路容易断连

问题：上位机、ESP32、MaixVision 之间同时存在 UDP 和 TCP，任一设备重启都可能断链。

解决：上位机网络线程采用自动重连；ESP32 通过广播注册请求寻找 GUI；链路监测通过 `PING/PONG` 周期性刷新状态。

## 2. 视频流卡顿

问题：TCP 视频帧如果读取不完整，会导致解码失败或 UI 卡顿。

解决：视频帧使用 4 字节长度头；上位机按长度读取完整帧，并设置超时、最大帧大小和显示帧率限制。

## 3. 自动对齐抖动

问题：色块中心点会受光照和识别噪声影响。

解决：对齐算法只输出离散微动指令，结合容差阈值和微步时间，减少过冲。

## 4. 麦轮方向不一致

问题：电机安装方向或接线不同会导致四轮运动方向不一致。

解决：STM32 固件保留 `motor_dir[4]` 方向校正数组，现场只需修改对应轮子的符号。

## 5. 敏感配置容易误提交

问题：WiFi 密码、Token 和设备地址在调试阶段容易硬编码。

解决：ESP32 私密配置移入 `config.h`；仓库只保留 `config.example.h`；`.gitignore` 阻止提交真实配置。
