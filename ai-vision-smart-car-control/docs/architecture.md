# 系统架构

## 分层设计

系统按“感知层、网关层、执行层、交互层”拆分：

- 感知层：MaixVision 摄像头负责采集图像、色块检测、黑线检测和视频推流。
- 网关层：ESP32-S3 负责 WiFi 网络、UDP 指令转发、MCP/WebSocket 接入和串口桥接。
- 执行层：STM32F103 负责底盘电机、RGB 灯和蜂鸣器；机械臂控制板负责动作组执行。
- 交互层：Qt/C++ 上位机负责实时操控、视频显示、状态监控、日志和模式切换。

## 数据流

1. 上位机通过 UDP 向 ESP32-S3 下发底盘、灯光、机械臂和模式指令。
2. ESP32-S3 将底盘命令转发到 STM32，将机械臂动作组命令转发到舵机控制板。
3. MaixVision 通过 TCP 向上位机推送 JPEG 视频帧。
4. MaixVision 通过 TCP 输出色块坐标和循迹黑线结构化数据。
5. ESP32-S3 可通过 MCP/WebSocket 接收外部工具调用，再转换为上位机可执行的 UDP 指令。

## 设计取舍

- 将运动执行放在 STM32，保证底盘响应稳定。
- 将网络和云端能力放在 ESP32-S3，降低 STM32 固件复杂度。
- 将视觉算法放在 MaixVision，避免上位机承担实时图像处理压力。
- 将复杂交互放在 Qt 上位机，便于调试和演示。
